# Contribute to the Catalogue

Suggest a tool, fix a page, or tell us what is missing.

## Suggest a Tool

1. Check the [inclusion criteria](#open-tool-criteria).
2. [Start a discussion](https://github.com/napcore-tools/web-awesome_napcore_tools/discussions/new?category=tool-suggestions) in the Tool Suggestions category. The [example suggestion](https://github.com/napcore-tools/web-awesome_napcore_tools/discussions/2) shows what to include.
3. The NAPCORE team reviews the suggestion and replies in the discussion. Once it is accepted, we add the tool to the catalogue.

## Inclusion Criteria {#open-tool-criteria}

A tool is included when:

- It supports European mobility data standards or workflows.
- It is openly accessible: open source or free to use.
- It works and has basic documentation.

Open source tools are preferred. The criteria are discussed in [Scope & Criteria](https://github.com/napcore-tools/web-awesome_napcore_tools/discussions/categories/scope-criteria).

## Other Ways to Contribute

- Fix or extend a page with "Suggest changes to this page" at the bottom of any page.
- Report a broken link or wrong information in an [issue](https://github.com/napcore-tools/web-awesome_napcore_tools/issues).
- Propose a category, a feature or another improvement in [Ideas & Feedback](https://github.com/napcore-tools/web-awesome_napcore_tools/discussions/categories/ideas-feedback).
- Add a tool yourself with a pull request, either as a [hand-written page](https://github.com/napcore-tools/web-awesome_napcore_tools/blob/main/TOOLS.md) or from a [publiccode.yml](https://github.com/napcore-tools/web-awesome_napcore_tools/blob/main/PUBLICCODE.md).

## Questions

Ask in [Q&A](https://github.com/napcore-tools/web-awesome_napcore_tools/discussions/categories/q-a).
